🔑 Setup API Keys

To see real restaurants near you, add these two free API keys:

1
Google Places API

Go to console.cloud.google.com → Create project → Enable Places API → Create credentials → Copy API key.

2
Google Gemini API (Free)

Go to aistudio.google.com/app/apikey → Create API key → Copy it.

3
Add to your project

In your project folder, rename .env.example to .env and paste your keys.

GOOGLE_PLACES_API_KEY=AIza...
GEMINI_API_KEY=AIza...
4
Restart the server

Run npm start again in your terminal. The app will switch to live mode automatically.
